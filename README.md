# Real-AC-SLAM
**Real-AC-SLAM** is the real-world implementation of the **Autonomous Collaborative SLAM (AC-SLAM)** project. It provides a complete ROS 2 software stack for autonomous exploration, navigation, localization, and collaborative mapping using multiple mobile robots. The platform supports both a custom differential-drive robot and the Robotino omnidirectional robot, enabling robots to independently explore unknown environments while collaboratively building a shared global occupancy map.

### Differential Drive Robot

This branch contains the complete software stack for the custom differential drive mobile robot developed for collaborative autonomous exploration and SLAM.

The robot is based on **ROS 2 Humble**, **Raspberry Pi 5**, **STM32F407**, and **RPLIDAR A2**, and supports autonomous exploration using Nav2 while collaboratively building a global map with multiple robots.

# Installation

Clone the repository

```bash
git clone https://github.com/Aymen-Jocef/Real-AC-SLAM
```

 Build the docker container
```bash
docker compose build
```

 Start the container

```bash
docker compose up 
```
# Startup Script

The Docker container uses a custom startup script:

```
entrypoint.sh
```

This script is responsible for:

1. Sourcing the ROS 2 environment
2. Sourcing the workspace
3. Configuring environment variables
4. Launching all required ROS 2 nodes
5. Keeping the container running

Enter the running container 
```bash
docker exec -it ac-slam bashh
```

Build

```bash
cd ~/Real-AC-SLAM

colcon build

source install/setup.bash
```

# Multi-Robot Deployment

Each robot runs independently using its own namespace.

Example

```
/robot1
/robot2
```

Each robot publishes

- map
- tf
- odom

The merged map is generated by the map merging package.
```bash
https://github.com/abdulkadrtr/mapMergeForMultiRobotMapping-ROS2
```

# Hardware Communication

The Raspberry Pi communicates with the STM32 through USB serial.

The STM32 performs

- encoder reading
- PID speed control
- wheel velocity control
- odometry computation

while ROS performs

- localization
- navigation
- exploration
